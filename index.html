Spade email signature

Fill in your details, then copy the signature into Gmail.

  1. Click Copy signature.
  2. In Gmail, open Settings, then See all settings, then General, then Signature.
  3. Create a new signature, click in the box and paste (Ctrl+V or Cmd+V).
  4. The logo loads from this page's web address, so Gmail keeps it. If it still does not show, click the image icon in the signature box and add the logo by its web address.
  5. Choose it as the default for new emails and replies, then save.
